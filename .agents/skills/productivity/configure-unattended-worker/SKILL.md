# Configure Unattended Worker Skill

This skill teaches the Interactive Architect AI (Terminal A) how to automatically and silently configure background worker parameters on behalf of the human user without requiring the human to type shell flags.

---

## When to Use This Skill
Activate this skill whenever the user in conversation says things like:
- "I want to reference an external project at `/path/to/repo`"
- "Switch worker model to Claude / Gemini 3.8 / Flash-Medium"
- "Enable sandbox mode for the worker"
- "Increase worker timeout to 15 minutes"

---

## Autonomous Actions for Terminal A AI

### 1. External Reference Directories
When the user mentions an external reference folder:
1. **In `.worker.env`**: Update or create `.worker.env` in the repo root:
   ```bash
   ADDITIONAL_DIRS="/absolute/path/to/external/repo"
   ```
2. **In `tasks.txt`**: When writing tasks that need external reference, specify the absolute path in the `ACTION` field:
   ```text
   TASK-007 | TARGET: src/feature.py | ACTION: Port implementation from /absolute/path/to/external/repo/src/feature.py | VERIFY: pytest tests/ | CONSTRAINTS: Only modify local src/feature.py
   ```

### 2. Model & Sandbox Adjustments
When the user requests different models, timeouts, or sandbox isolation, write to `.worker.env`:
```bash
# Generated by Architect AI
AI_MODEL="gemini-3.8-flash-medium"
AI_EFFORT="low"
USE_SANDBOX="1"
TASK_TIMEOUT="900"
```

### 3. Verification
Confirm the configuration to the user in concise Chinese:
> "已為您自動設定好背景 Worker 的參考目錄與參數（寫入 `.worker.env`），您只需直接在終端機輸入 `./worker.sh` 即可自動套用，無需手動輸入任何參數。"
